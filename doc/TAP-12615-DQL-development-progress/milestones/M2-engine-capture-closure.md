# M2 Engine 捕获闭环

## 1. 里程碑结论

M2 已完成（待集成验证）。阶段 C01-C12 已覆盖 Engine 公共 DQL 契约、Payload 快照、身份生成、异常分类、Storm Guard、目标/处理节点捕获、TM 上报以及捕获回归。

## 2. 能力证据

- 记录级异常只有在 DQL 保存确认后才允许 skip；共享异常继续走任务级重试/错误路径。
- Insert、Update、Delete 的 Payload 使用版本化 JSON 快照，并对完整 Payload、预览和敏感字段执行边界保护。
- 目标写入和处理节点捕获均保留原始上下文；JS/自定义处理节点的脚本异常分类已纳入捕获链路。
- Storm Guard 在任务、节点、表、错误码和归一化消息维度限制异常风暴，并避免把共享异常拆成大量 DQL 记录。
- C12 回归覆盖正常 DQL 捕获、保存失败不 skip、共享异常任务级重试和后续成功语义。

## 3. 状态边界

当前工作区已具备 Engine 捕获实现和定向回归，但真实 TM/Engine 联调、故障注入、默认告警发送和存量任务兼容性仍属于 G02-G04、F02-F07、G10 的验收范围。因此 M2 标记为“已完成（待集成验证）”，不宣称生产集群验收完成。
