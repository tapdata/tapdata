# 开发步骤 23：移除脚本参数说明列

## 实现目标

按界面需求移除“脚本参数”表格中的“说明”列，释放更多空间给参数值输入区域。

## 代码变更

- 删除“说明”表头和每行的说明输入框。
- 删除说明列对应的 `<col>` 和样式。
- 将参数名、类型、参数值、加密和操作列重新分配宽度，参数值列占用主要空间。
- 保留参数对象中的 `description` 字段读取和序列化能力，避免已有任务配置被打开后丢失。

## 自审与验收

- 表格只展示参数名、类型、参数值、加密、操作五列。
- 加密开关、删除按钮和重复 key 校验行为保持不变。
- 脚本参数单测 5 项通过，Prettier、ESLint 和 i18n 检查通过。
